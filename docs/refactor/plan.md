## 5. 迁移与兼容策略

- 数据兼容：Redis key、TTL、JSON、默认值、回退状态共享方式都不改。需要改数据格式时另立功能/迁移方案。
- 接口兼容：`mako-bot`、插件配置名、QQ 命令和 Dashboard URL/JSON 保持。
- Python 内部导入可迁移；过渡 facade 保留必要旧调用。最后全仓检查引用后删除非公共兼容壳，控制目录文件数。
- 插件同名 `.py` 转包必须同一模块原子处理，不同时留下 `chat.py` 与 `chat/__init__.py`。
- 存储改组合式仓库，显式共享一个后端状态；不做多继承、动态转发或一仓库一份内存字典。
- 前端只拆分资源，保持 DOM、样式级联和 API；ES modules 从同源静态路由加载，不新增构建依赖。
- 测试按领域迁移且保留发现数量、fixture/monkeypatch 语义；不以删测试来达标。
