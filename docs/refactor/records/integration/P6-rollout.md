# P6 发送补记切换与回退边界

2026-09-27。本文件是待发布检查说明，不是发布授权或上线完成记录。
代码依据：delivery/effects/producer.py、discovery.py、state/effect_legacy.py、plugins/chat/recovery.py。

## 当前实现

- 跟进、定时资讯/问候、提醒在发送前保存冻结计划；确认sent时原子激活任务。
- 即时补记与30秒后台扫描共用任务租约、稳定effect_id与目标回执。
- 后台任务还包含未来提醒缓存恢复及有效发送恢复；关闭某项业务发送开关不等于关闭sent补记。
- 发送恢复检查原bot、目标、业务开关与截止时间；sent补记不需要bot在线，不重新发送消息。
- 旧sent没有完整计划时不补造历史或去重任务，仅对满足旧格式身份校验的永久记录CAS标待核对。
- 人工确认但实际时间未知时，时间相关任务待核对；原版本源完成可独立执行。

## 发布前必须完成

1. 独立核对目标回执、源版本、冻结计划、租约及生产入口；设计报告不替代实现复审。
2. 核对实际运行实例及其代码版本，确认没有旧发送器继续进行直接补记。
3. 为当前应用版本与Redis持久化证据准备受控备份；本地测试不证明生产Redis持久性。
4. 停止接收新发送任务，等待在途传输和补记退出，再停止旧应用进程。
5. 对无法排空的传输保留unknown/待核对，不凭进程退出推断未发送，不重置记录。
6. 确认旧进程全部退出后，才启动统一版本的新发送器与消费者。不得让旧直写和新回执写入同时工作。

没有新增一键关闭所有恢复的配置；不要把PROACTIVE_ENABLED=false解释成全局停机开关。
上述运行操作尚未执行。真实部署、生产读写与QQ联调需按用户明确授权范围进行。

## 运行时核对

Owner私聊“发送状态 <动作ID>”分别查看发送事实和各补记任务；查询不会触发补记。
“发送列表 [游标]”用于逐页定位动作，不是事务快照。后台扫描的COUNT不是Redis服务端工作量硬上限。
补记Redis故障后保留任务与分页位置；服务端错误或无效载荷进入待核对，不按网络超时盲重试。
pending不证明目标从未写入，sent也不证明后续记录全部完成。不得手工复制动作ID或清除receipt来强制重试。

## 回退

先停用应用并排空发送与补记，再更换代码；保留执行记录、冻结计划、源版本、意图和永久目标回执。
代码回退不等于数据回滚。不得直接启动缺少新协议认知的旧发送器处理已有任务，也不得删除Redis证据重新发送。
发现新协议问题时，保留待核对记录并修复后继续相同任务ID；无法证明目标结果的记录由Owner核对。
回退只读Owner展示可单独撤销显示代码；这不会撤销已经发生的送达或补记。

## 验证限制

已有隔离Redis验证覆盖响应丢失、取消线程、租约接手、源改版、部分目标失败和人工未知时间。
不覆盖生产进程升级、Redis持久化灾难恢复、真实QQ传输或实群自然度；没有exactly-once全链路承诺。
聊天历史与B1审批的可靠补记仍需各自接入方案，不能由上述三类后台入口推断已经覆盖。普通聊天生成费用已单独接入G1，不属于P6的sent后补记。

## 2026-10-05 H1切换补充

普通主回复当前已切换新历史链路，旧ChatEngine.commit仅保留兼容定义，没有普通pipeline调用；这不是部署记录。生成费用与送达/历史任务分离，保存发送计划失败不重做模型。确切快照读取失败会暂停生成，不以空历史继续覆盖。
聊天历史使用mako:chat:delivery:v1的完整1MiB以内冻结计划、mako:chat:history:v1:effect永久会话结果及既有全局效果回执；升级/回退不得删除这些证据。超过5分钟sending的合法永久记录只分类unknown，禁止重新begin，原token可晚ACK收尾。后台扫描每页最多10键/2任务，分类不承诺即时；COUNT不是服务端工作量硬上限。
Owner私聊“聊天历史状态 <动作ID>”“聊天历史列表 [游标]”只查询元数据；“聊天历史核对 <动作ID> 已送达/放弃”只转换unknown并持久操作者/核对时间/结论，人工已送达不填写实际送达时间、两历史保留待核对。晚ACK和相反结论不能覆盖人工结论；放弃不等于未送达。送达与两个历史结果分别展示，会话基线冲突不是发送失败；反馈不展示原始正文/快照/token、不触发补记或重发。新增人工来源分支仍为v1，缺来源的旧记录只按传输分支处理，旧程序不理解新记录时需故障关闭，回退不能删除字段以恢复发送资格。
发布仍须完成H1d分项/综合复核及P6/G2剩余检查，并停掉所有旧主回复直写进程。新消费者不能与不读永久回执的旧重放程序共存。未经核对的旧部分写入、时间丢失/舍入、坏计划保持待核对；无实群或生产持久化验收。
