## P3：关闭异常会覆盖原取消异常（受控复合故障）

位置：**src/services/tools/media.py:25–32**，尤其 finally 中未保护的 `f.close()`；外层 **34–40** 重新抛出的是替代后的异常。

复现前提：文件替身 write 抛 CancelledError，退出及重试 close 抛 OSError 且保持打开。实际得到 OSError，而非 CancelledError；上层 executor.py 的 `except Exception` 可以将其作为普通工具失败处理。路径仍登记，但打开句柄不能由只保存 Path 的 TemporaryFiles 关闭。

**限制**：这是故障注入下的确定行为，不是已经证明普通 task.cancel 会在同步 write 期间注入取消。当前同步段无 await，本轮普通任务取消探针通过。因此定为 P3 健壮性改进，不升级为常规取消回归或阻断项。建议保留正在传播的 BaseException，另外记录关闭故障；追加复合故障测试，明确持续关闭失败的资源归属。

在仓库根用现有 Python `-B -` 执行以下 stdin 内容即可复现，不导入配置或业务适配器：

```python
import ast, asyncio, pathlib, tempfile
from unittest.mock import patch

p = pathlib.Path('src/services/tools/media.py')
tree = ast.parse(p.read_text(encoding='utf-8'))
node = next(n for n in tree.body
            if isinstance(n, ast.FunctionDef) and n.name == '_media_file')
ns = {}
exec('import tempfile\nfrom pathlib import Path\n'
     'from contextlib import contextmanager\n'
     'from typing import Callable, Iterator', ns)
exec(compile(ast.Module(body=[node], type_ignores=[]), str(p), 'exec'), ns)
real = tempfile.NamedTemporaryFile
handles, tracked = [], []
with tempfile.TemporaryDirectory(prefix='b4-review-') as root:
    class FaultFile:
        def __init__(self, **kw):
            self.f = real(dir=root, **kw)
            self.name = self.f.name
            handles.append(self)
        @property
        def closed(self): return self.f.closed
        def __enter__(self): return self
        def __exit__(self, *args): self.close()
        def write(self, data):
            self.f.write(data)
            raise asyncio.CancelledError('original cancellation')
        def close(self): raise OSError('close failure')
    try:
        with patch.object(tempfile, 'NamedTemporaryFile', FaultFile):
            try:
                with ns['_media_file'](b'x', '.png', tracked.append):
                    pass
            except BaseException as exc:
                print(type(exc).__name__, str(exc))
                assert isinstance(exc, OSError)
    finally:
        for handle in handles: handle.f.close()
        for path in tracked: path.unlink(missing_ok=True)
```
