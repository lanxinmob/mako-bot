# 更新记录

[返回 README](../README.md) · [English](en/CHANGELOG.md)

## 2026-10-10

- 增加群聊节奏合成回放、评测指标和面板中的近期决策状态。
- 支持在本人私聊中查看记忆来源、纠正或遗忘记忆，也可以明确授权重新记录。
- 增加考试计划、一次考前提醒和需本人同意的考后回顾流程。
- 普通提醒支持在私聊中创建、查看、修改和取消，到时发送给本人。

## 2026-10-06

- 新增小鸟、历史传送和真实期刊查询。
- 小鸟和历史传送支持随机抽取，也可指定鸟种、时代或地点。

## 2026-07-05

- 图片处理增加下载大小上限、解码前尺寸校验、用户级速率限制和临时文件清理，减少低内存环境中的资源占用。
