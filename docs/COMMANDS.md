# 命令与使用

[返回README](../README.md) · [配置](CONFIGURATION.md)

## 对话

私聊中发送普通消息；群聊中通过@机器人明确发起对话。是否回应还受黑名单、会话节奏、
预算和候选有效性检查影响。角色设定与记忆为模型提供上下文，不构成永远不偏离人设的保证。

天气、网页检索、笔记和提醒等能力可由聊天工具流程调用。外部服务需要配置相应凭据，
工具名单与用户权限决定是否允许执行。

## 小鸟、历史传送与期刊

启用 `discoveries` 插件。以下命令支持直接发送、添加机器人昵称或@机器人；
参数与命令用空格分隔，不调用付费模型。

| 命令 | 行为 |
| --- | --- |
| `/help` | 显示小功能与人物档案的用法 |
| `小鸟` / `今日小鸟` | 随机抽取鸟种与可复用图片 |
| `小鸟 麻雀` / `小鸟 Passer montanus` | 按中文名或学名查询 |
| `传送` | 随机历史背景与生活小故事 |
| `传送 唐朝` / `传送 埃及` | 按时代或地点筛选 |
| `传送 再来` | 换一个候选 |
| `期刊 Nature` | 按刊名查询真实刊物 |
| `期刊 1932-6203` | 按ISSN查询 |
| `发表` / `投稿` | 查看每日刊物候选 |
| `投稿 machine learning` | 按近期论文主题寻找相关刊物 |

小鸟从iNaturalist等资料中选择可复用图片；在线资料不可用时有有限的离线鸟图。
图片保留物种、作者、来源与许可。历史背景标注史实出处，生活故事为原创虚构，两者分开说明。
期刊查询提供Crossref记录和论文DOI，不填写无法可靠核对的分区、影响因子或版面费；
投稿前仍应核对刊物官网的范围与要求。

小鸟和历史传送按用户打乱轮换，候选池耗尽后再次循环；轮换状态在重启后清空，
筛选只剩一个候选时可能重复。同一人在同一会话三秒内重复相同命令会静默忽略，
不同命令仍经过发送队列限频。未获得可靠数据时可能返回来源不可用的说明。

这些命令也检查全局、群聊/私聊工具名单和黑名单，并在发送前再次检查权限。
对应工具名为 `discoveries.bird`、`discoveries.journey`、`discoveries.journal` 和
`discoveries.help`；已有允许名单时需包含要使用的工具。

## 人物档案与个人关系记忆

| 命令 | 权限与行为 |
| --- | --- |
| `人物档案` | 仅owner：显示档案总数及最近更新的前5人 |
| `人物档案 ID` / `人物档案 名称` | 仅owner：查看完整档案；重名时列出ID |
| `可塑性记忆` / `memory` | 人物档案的旧命令，同样仅owner可用 |
| `/关系记忆`、`我的记忆` | 本人私聊查看条目、ID、状态与来源；有效条目优先 |
| `解释记忆 <记忆ID>` | 查看真实来源片段和时间；旧条目明确说明来源未知 |
| `/纠正记忆 <记忆ID> <新陈述>` | 只更正同类型、同主题；生成新ID，原条目已替换 |
| `/删除记忆 <记忆ID>`、`忘掉记忆 <记忆ID>` | 清空同主题账本及来源，清理精确镜像，停止跟进；历史聊天保留 |
| `重新记住 <记忆ID> <新陈述>` | 明确重新授权已遗忘主题，生成新记录；不重新激活承诺 |
| `以前喜欢乌龙茶，现在不喜欢了` | 唯一匹配该主题时更正；歧义时选择ID |
| `忘掉这件事` | 仅接受引用本人在当前机器人五分钟内收到的记忆说明 |

人物档案由 `precipitate_knowledge` 插件提供，owner由 `AUTONOMY_OWNER_ID` 指定；
设置owner不要求开启自主行动。群里发起人物档案查询时也只私聊返回。
个人关系记忆由 `chat` 插件提供，不能通过这些命令修改他人的记录。
上述记忆命令也接受不带 `/` 的写法；群内只给通用私聊提示。首次更正或遗忘后采用
账本优先模式，暂停旧画像与无来源向量；存储不明时返回待确认，不能视作长期遗忘成功。

## 提醒、天气与资讯

| 命令或消息 | 要求 |
| --- | --- |
| `/我的提醒` / `/查看提醒` | `chat` 插件；查看当前会话中属于自己的提醒 |
| 在私聊或群聊中请求创建、修改或取消提醒 | 可用的 `DEEPSEEK_*` 配置及对应会话的消息发送权限；私聊提醒发送给本人，群聊提醒发送回原群 |
| `/天气 上海` / `/weather 上海` | `weather` 插件，以及 `QWEATHER_HOST`、`QWEATHER_KEY` |
| `/精选文章` / `/今日新闻` / `/日报` / `/news` | `scheduler` 插件；资料服务凭据按配置填写 |

NoneBot注册命令默认以 `/` 开头；如果自行修改NoneBot的命令前缀，使用相应前缀。
小功能与人物档案使用独立的显式解析方式，允许上表中不带 `/` 的写法。

首次使用提醒时，以 `/我的提醒` 中的时间和内容核对创建结果，再确认到时实际收到消息，
完整步骤见[首次体验](FIRST_RUN.md#3-从创建到实际送达的一次提醒)。

## 考试陪伴

在 `PLUGIN_ENABLE_LIST` 中增加 `companion` 后启用。只接受本人私聊，每人最多一个进行中的计划，
每个计划有 1–3 个自填任务、一次提醒，以及明确同意后的一次回顾邀请；这些命令不调用模型。
以下完整命令均可带 `/`。示例日期须换成符合条件的未来日期，ID 使用创建回执中的值。

```text
创建考试计划 数学期中 | 考试=2026-10-20 09:00 | 提醒=2026-10-19 20:00 | 任务=复习第三章；完成一套真题
我的考试计划
查看计划 ID
修改计划 ID 提醒=2026-10-19 21:00 | 任务=整理错题
同意回顾 ID 2026-10-20 20:00
撤销回顾 ID
提交回顾 ID 完成=1,2 | 感受=有些紧张 | 下次=提前整理错题
取消计划 ID
忘掉计划 ID
```

时间固定为北京时间（Asia/Shanghai）。考试须在未来90天内；提醒至少在接收5分钟后、考试5分钟前。
回顾邀请须在考试后、考试后7天内，并至少在接收5分钟后；完成序号只接受当前任务序号或 `无`。
`|` 与 `；` 是保留分隔符，正文不能包含它们或换行。名称最多40字、任务100字，感受与下一步各200字。
不接受引用、媒体、凭据或他人授权。回顾不回复时不追问，考试后7天安静关闭。

查询分别显示计划、授权、主发送和补记。只有明确 QQ 确认才显示 sent；unknown 可能已发送，不自动重发。
提醒尚未明确送达并完成补记时，自动回顾暂停；考试后本人仍可直接提交回顾。
任务或时间修改撤销旧回顾授权；提醒已进入发送后不能重新包装它进行修改。
取消、撤销和遗忘停止未开始动作；已经开始的发送无法撤回。超出各步骤30分钟窗口不补发。

计划独立于关系记忆。遗忘清空该计划、步骤正文和精确关联笔记，并沿用记忆控制过滤旧材料；
其他关系记忆与私人笔记保留。原始聊天、已经发送的内容、送达审计与备份仍保留。
Dashboard 的“考试陪伴”页只读，沿用 token 鉴权。此流程依赖可确认的 Redis 和一个活动机器人进程。

## 消息历史

已确认送达的插件消息按机器人和会话单独保存最近20条，用于后续引用，
与普通聊天历史分开。普通历史容量由 `MAX_HISTORY_TURNS` 控制，当前默认50。
插件历史可在Redis不可用时暂存内存，重启后未持久化的记录会丢失；
这不代表主聊天生成、历史提交和恢复流程也能完整使用内存运行。
